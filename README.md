# Clack

Клавиатура для Android-телефонов с физической клавиатурой (сделана под Unihertz Titan 2).
Лёгкая: APK около 2 МБ, без экранной клавиатуры — только тонкая полоска с языком и подсказками.

## Что умеет

- **Раскладки в формате Pastiera** (JSON). Подходят её файлы и веб-редактор
  [pastierakeyedit.vercel.app](https://pastierakeyedit.vercel.app/). В комплекте ЙЦУКЕН и QWERTY;
  свои раскладки импортируются в настройках.
- **Смена раскладки** сочетанием клавиш — по умолчанию Fn+Space (Alt+Space тоже работает),
  в настройках можно записать любое. Ещё — тап по метке языка на полоске.
- **Alt-слой** (цифры и символы, как напечатано на клавишах Titan 2), Shift и Alt «залипают»:
  одно нажатие — для следующей буквы, двойное — фиксация.
- **Мульти-тап** для букв, которым не хватило клавиш: е→ё, з→х→ъ, д→ж→э, ь→б→ю.
- **Подсказки и автоисправление**, которые знают, где стоят клавиши: «пртвет», «приает», «ппивет»,
  «првиет», «приввет» → «привет». Учитываются соседние клавиши, лишние/пропущенные буквы,
  перестановки, промахи мульти-тапа и ё/е.
- **Предсказание следующего слова** по тому, как пишете вы. Можно сразу обучить на своей
  переписке: импорт экспорта Telegram Desktop (`result.json`). Всё хранится только на телефоне.
- Бэкспейс сразу после автоисправления возвращает набранное слово (и больше его не исправляет).
- Двойной пробел → точка, заглавная в начале предложения, долгое нажатие → символ Alt или заглавная.

## Установка

1. Скачайте `clack.apk` со страницы **Releases** и установите.
2. Откройте Clack → «Включить Clack» → включите в списке клавиатур → «Выбрать клавиатуру».

## Устройство проекта

- `core/` — чистый Kotlin без Android: раскладки, модель опечаток, словарь, предсказание.
  Покрыт тестами (`./gradlew :core:test`), включая реальные русские опечатки.
- `app/` — сервис ввода, полоска подсказок, настройки, импорт Telegram.
- `tools/build_dictionary.py` — сборка словарей из `wordfreq` с отсевом частых ошибок.

Сборка: `./gradlew :app:assembleRelease`. GitHub Actions собирает APK на каждый коммит в `main`
и выкладывает его в релиз `latest`.

Данные словарей: wordfreq, CC BY-SA 4.0 — см. [NOTICE.md](NOTICE.md).
